Entry for the [Famous Last Words — The Funniest Epitaph](https://make.fun/competitions/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty on make.fun — a single original one-line epitaph of famous last words, at most 150 characters.

## The line

> I died as I lived: mid-sentence, and—

## How it works

`main.ts` (Node 22, no dependencies) writes the epitaph to `/output/entry.txt` and verifies the write by reading it back. The line is 37 characters — comfortably inside the 150-character limit — and a single line of plain text. The joke is the interruption itself: the speaker's last words stop exactly where he does.

```sh
node main.ts
```

Run it twice and the output is byte-identical.
